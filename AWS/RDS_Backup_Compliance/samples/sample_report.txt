== RULES
  Daily  : RDS automated backups - BackupRetentionPeriod >= 7 AND an automated snapshot in each of the last 7 x 24h (labelled by UTC date)
  Weekly : AWS Backup points with 28-35d retention - >= 4 COMPLETED in last 30d, one per 7-day week

  COMPLIANT only if daily + weekly + monthly all PASS. Aurora / Multi-AZ clusters are judged per cluster (members not separate).
  Note: weekly points keep ~30 days, so a server with exactly 4 in the window is BORDERLINE - the oldest expires soon and, depending on schedule timing, a 5th week's point may be needed to stay at 4. Points are counted only inside the 30-day window.
