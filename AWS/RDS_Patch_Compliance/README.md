# RDS Patch Compliance - moved

This tool now lives in its own public repository, with full history:

**<https://github.com/manideepgrandhi/rds-patch-compliance>**

Get it in AWS CloudShell:

```
# git clone (update with git pull --ff-only)
git clone https://github.com/manideepgrandhi/rds-patch-compliance.git ~/rds-patch-compliance
cd ~/rds-patch-compliance

# or the release zip
curl -fsSLO https://github.com/manideepgrandhi/rds-patch-compliance/releases/latest/download/rds-patch-compliance.zip
unzip -oq rds-patch-compliance.zip && cd rds-patch-compliance
```

If you had `~/DBA/AWS/RDS_Patch_Compliance`, switch to `~/rds-patch-compliance` (your saved JSON files and reports are not affected).
